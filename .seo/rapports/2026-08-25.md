## Alertes

### 🔴 Alerte haute — écart d'orthographe de marque entre le prompt et le site en production

Le site live `https://optimasprotect.ma/` (désormais accessible en fetch, voir ci-dessous) affiche systématiquement **« OptImasProtect »** (un seul mot, I majuscule médian) dans le `<title>`, les meta OG/Twitter, le footer et l'alt du logo. Le prompt de référence (§1) impose pourtant **« Optimas Protect » en deux mots** comme orthographe non négociable, avec l'exemple explicite « jamais OptImasProtect ». J'ai continué d'appliquer la règle du prompt dans l'article produit ce run, mais cette contradiction directe entre la charte et le produit réel mérite un arbitrage humain : soit corriger le prompt pour refléter le nom réel du produit, soit corriger le site.

### 🟠 Alerte — site live accessible mais probablement non connecté au dépôt de contenu

Nouveauté ce run : `https://optimasprotect.ma/` répond maintenant correctement en fetch (ce n'était pas le cas aux runs précédents). Le contenu récupéré montre un site marketing complet et fonctionnel (6 modules produit, tarifs conformes au prompt, CTA WhatsApp), mais **sans aucun lien ni section `/blog/`** dans la navigation ou le footer. Les assets pointent vers `storage.googleapis.com/gpt-engineer-file-uploads/...`, ce qui suggère un site généré par un outil tiers distinct de ce dépôt Git. Les 7 articles produits à ce jour ne peuvent donc toujours pas devenir des pages live sans intervention humaine (générateur à brancher sur ce dépôt, ou section blog à intégrer au site existant).

### ⚪ Point technique — `robots.txt` non vérifiable ce run

L'outil de fetch de cette session a bloqué l'URL `https://optimasprotect.ma/robots.txt` (restriction de provenance de l'outil, pas un problème du site). Impossible de confirmer si l'indexation du blog serait autorisée. À revérifier au prochain run.

### ⚪ Point positif — conventions de contenu validées

Le format de frontmatter et le dossier `content/blog/{slug}.md` établis au premier run fonctionnent sans ajustement : le commit de l'article de ce run a été réalisé sans erreur.
